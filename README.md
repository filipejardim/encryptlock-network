# EncryptLock network data

Public data of the EncryptLock blockchain (`encryptlock-1`), refreshed about every 10 minutes, for outside tools such as the Cosmos chain-registry and explorers.

- REST: https://filipejardim.github.io/encryptlock-network/rest
- RPC: https://filipejardim.github.io/encryptlock-network/rpc

These are snapshots (latest block, node info, LockKeepers, supply), not a live node. The EncryptLock app and website talk to the network directly.

EncryptLock: https://encryptlock.pages.dev · Downloads: https://github.com/filipejardim/encryptlock-downloads

The code in this repository may be read but not copied, modified or reused (same terms as https://github.com/filipejardim/encryptlock-downloads).
